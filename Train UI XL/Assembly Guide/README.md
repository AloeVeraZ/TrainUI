This folder is ready for the full Train UI XL assembly guide. I am keeping the build photos and each step here so the software setup and physical assembly do not get mixed together in the main README.

For now, use the complete [bill of materials](../README.md#parts). The individual listing photos are stored in [`images/parts/`](images/parts/) so they are still available if an Amazon listing changes or disappears.

> [!WARNING]
> Do not power the build while cutting, stripping, soldering, or checking continuity. Mount the USB-C socket board to the printed back piece before soldering the internal cable; replacing that back piece later requires desoldering and resoldering the connection.
