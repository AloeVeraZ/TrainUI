# TrainUI enclosure CAD

This folder is reserved for the TrainUI enclosure's printable and editable CAD files.

The enclosure is being designed as three 3D-printed parts around the main project hardware:

- Original Raspberry Pi Zero W.
- HAMTYSAN 10.1-inch 1024×600 HDMI display ([Amazon ASIN B0FMF3RTPC](https://www.amazon.com/dp/B0FMF3RTPC)).
- Heat-set threaded inserts and fasteners through matching assembly holes.

The CAD models are still in development. Source models, printable exports, hardware notes, and assembly guidance will be added here when the enclosure design is complete.
